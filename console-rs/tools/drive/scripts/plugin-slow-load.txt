# A plug-in load the daemon takes 8 s to commit (a native load) feels instant: on the drop the slot
# shows the plug-in loading ("…") and its window opens at once, locked ("LOADING…"); at the commit
# the same window goes live without reopening. A load the daemon refuses after its seconds closes
# the window, empties the slot and shows the reason.
#: --catalogue --specs --daemon-arg=--load-delay --daemon-arg=8 --daemon-arg=--refuse-load --daemon-arg=EQ
settle
dragto browser:BrowserItem(0) /devices/0/inputs/0:Insert(0)
wait 300
layer plugin:/devices/0/inputs/0:0

text Test Comp…
